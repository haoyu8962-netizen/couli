## 1. 问题

B1-18c 让淘宝适配器输出了补贴类佣金之后，核查发现快照与订单会对不上：

1. 补贴单独变了、有效联盟佣金 N 没变时，不产生新版本（BR-CALC-15 原文「只有新 N 与已存值不同时才 +1」）。快照四段金额里含补贴的三段（联盟佣金总额、基数前扣除、平台预估利润）停在旧补贴。
2. 之后 N 变化写新版本时，实现沿用首次快照冻结的补贴，不取订单当时的补贴，与 BR-CALC-27「按该版本落四段金额」不符。
3. 例：快照时 n_base 800、补贴 200，v1 联盟佣金总额 1000。只有补贴变成 350，订单列是 350，快照仍是 1000。N 再变成 900，v2 写成 900 + 200 = 1100，按订单当时的值应为 1250。

眼下没有实际影响：R1 联盟对账与毛利报表都没实现，入账开关默认关。但 R1 以后读快照会和联盟总额对不上，报出假的差错单。
