# 变更记录：App 页面底改近中性（2026-11-25）

- 状态：已写回（负责人 2026-11-25 在对话中从六个候选里选定 C：「选 C」）
- 来源：负责人反映三端背景色「看起来不是很舒服」。代理核对的结论：原页面底 `#F2EEE6` 往黄色偏（CIELAB a* ≈ 0、b* +4.3），和系统键盘、弹窗、玻璃栏的中性白以及商品白底图不是同一套白；页面底、次要分组、图片占位、描边四层米色亮度接近、色调相同，层次发糊。代理把 A–F 六个候选放在同一个首页示意上做了对比页（可切换配套色、模拟屏幕偏暖、弹出键盘），负责人选 C。对比页放在负责人的私有 Artifact，不进本仓库。
- 类别：改了 2026-10-04 已确认的 App 页面底（`docs/changes/20261004-设计方向第三轮.md` §1 第 4 项），属于对外可见的视觉口径。负责人在对话中明确选定，按 00 §8 直接回写。不涉及金额口径、订单归属、用户授权，也不涉及对外承诺。
- 范围：不改 D 编号决定，不涉及 BR、F、AC 编号与错误码。深色取值、管理后台页面底 `color.background.admin-canvas`、文字色、品牌色、返利色、状态文字色都不变。

## 1. 改了什么

数值唯一源 `design/tokens/design-tokens.json`，版本 0.5.2 → 0.5.3。

| 令牌 | 原值 | 现值 | 说明 |
| --- | --- | --- | --- |
| `color.background.canvas` | `#F2EEE6` | `#F6F5F3` | App 页面底，令牌名不变 |
| `color.background.muted` | `#EFEAE2` | `#F2F1EF` | 次要分组底 |
| `color.status.pending.background` | `#EFEAE2` | `#F2F1EF` | 「预估中」「等待结算」浅底，原来就和 muted 同值 |
| `color.background.placeholder` | `#E9E2D9` | `#EBEAE7` | 图片占位底 |
| `color.button.primary.disabled.background` | `#E9E2D9` | `#EBEAE7` | 主按钮禁用底，原来就和 placeholder 同值 |
| `color.border.subtle` | `#E4DED5` | `#E6E5E3` | 装饰分隔线 |
| `color.source.border` | `#E4DED5` | `#E6E5E3` | 来源标签描边，原来就和 border.subtle 同值 |

配套色的取法：保持原来四层之间的亮度差（次要分组 −1.3、图片占位 −4.0、描边 −5.5，CIELAB L*），色调跟新页面底走。新页面底 L* 96.6、b* +1.1，黄偏约为原值的四分之一，只留一丝暖。

版本用补丁号：这次只改取值、不加键。v0.6.0 已在 05 任务表里留给 DSX-02（令牌升版一），验收写的就是 `metadata.version` 为 0.6.0，所以不占用。

令牌说明里把「米白底」改成「页面底」，涉及 `color.brand.primary`、`color.rebate.text`、`color.border.control` 三条。

## 2. 对比度

`design/colors/colors.md` §3.1 涉及这几个颜色的行全部重算过。文字组合仍都 ≥ 4.5:1，必要图形仍都 ≥ 3:1。主色 `#C44820` 在新页面底上是 4.49:1，仍不可作普通小字，规则不变。

## 3. 受影响的地方

- 规划仓库：令牌源与两份生成物（`design/tokens/variables.css`、`design/brand/brand-config.js`，由 `scripts/sync-brand.py` 生成）；`design/colors/colors.md` 的方向说明、§1、§2 和 §3.1；`design/tokens/README.md` 的主色对比说明；`design/brand/index.html` 的色板名称；`design/wireframes/admin-product-pool-v20261115.md` 的标签底由写死色值改为令牌名；`docs/brand-integration.md`；规划/00 §7、§8；规划/03 品牌接入段；规划/05 令牌版本说明。
- 三端与 H5：页面底用的令牌名不变，各自的令牌锁升到 v0.5.3（或更新的版本）后自动跟上；升锁前设备上仍是旧米色。写死旧米色值的截图或像素基线要随升锁重录，例如 `rebate-ios` 的 `UITests/HomeScreenPixels.swift`。跟锁由编排按现有跟锁单安排，本记录不新增任务行。
- 管理后台：页面底不变；共享的次要分组、占位、描边、禁用底跟着变成近中性。
- 接口与契约：无。契约里的令牌快照（CT-11c）照常跟版本。

## 4. 验收

1. `python3 scripts/sync-brand.py --check` 无漂移。
2. 品牌预览 `design/brand/index.html` 浅色、深色各看一遍，色板显示「近中性暖白」和新色值。
3. 三端与 H5 升锁后，按 11 的三端视觉验收做法看首页、列表和订单页：页面底、筛选标签、图片占位、描边、禁用按钮是同一套近中性，和系统键盘、弹窗、商品白底图放在一起不打架。

## 5. 恢复方式

把 §1 表里七个令牌改回原值，版本再升一个补丁号，运行 `python3 scripts/sync-brand.py` 并 `--check`，同步 `colors.md` 的表格与对比度；三端与 H5 跟锁。
